## Part F Troubleshooting

### Compiler download và môi trường ghi cache

Lần compile đầu báo:

```text
Error HHE904: Couldn't download compiler version 0.8.34+commit.80d5c536.
```

Lần lấy stack trace tiếp theo bị chặn trước khi chạy Hardhat bởi:

```text
npm error nospc ENOSPC: no space left on device, write
```

Công cụ terminal cũng từng không tạo được setup log do OS error 112. Chưa đủ
bằng chứng để phân biệt nguyên nhân mạng hay ghi cache của lần HHE904 đầu tiên.
Đã chuyển riêng npm cache sang ổ D bằng .npmrc, không xóa dữ liệu người dùng.
Retry Hardhat trực tiếp ngoài sandbox đã tải WASM compiler thành công và compile
được. Sau đó npm ci, compile, typecheck và tests đều được kiểm chứng lại.

Lần test trong sandbox báo:

```text
MultiProcessMutexTimeoutError: Timed out waiting to acquire lock at
C:\Users\lequa\AppData\Local\hardhat-nodejs\Cache\compilers-v3\compiler-download-list
after 60000ms
```

Sandbox chỉ cho ghi workspace, trong khi Hardhat dùng global compiler cache ở
AppData. Chạy cùng toolchain ngoài sandbox với quyền ghi cache giải quyết lỗi;
2 tests PASS. Không đổi major toolchain hoặc bỏ qua assertions.

### npm install scripts

npm 11.21 báo esbuild@0.28.2 có postinstall chưa được allowScripts xác định.
Đã phê duyệt đúng package/version bằng `npm install-scripts approve esbuild`,
lưu trong package.json. npm ci sau đó thành công và không còn script chưa review.

### Audit và deprecated dependencies

Full audit báo 13 package entries mức high, cùng bắt nguồn từ
[zod GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).
Advisory mô tả nguy cơ cạn bộ nhớ khi xử lý collection quá lớn. Phiên bản
zod đang dùng là 3.25.76; bản vá được advisory nêu là 4.6.6, ngoài major của
Hardhat/plugins hiện tại. Không ép override lên Zod 4 hoặc dùng audit fix --force.
Hướng khắc phục tiếp theo là cập nhật Hardhat/plugins khi hỗ trợ bản đã vá và
kiểm thử lại. Cảnh báo chưa được giải quyết; không tuyên bố toolchain hết lỗ hổng.
`npm audit --omit=dev --json` đã xác nhận dependency production có 0 advisories.

`npm explain glob inflight` xác định hai cảnh báo deprecated đến từ:

```text
hardhat-toolbox-mocha-ethers -> hardhat-typechain -> typechain@8.3.2
  -> glob@7.1.7 -> inflight@1.0.6
```

Giữ dependency ranges tương thích của upstream; không cài package trùng chức
năng hoặc ép đổi major gián tiếp. Các cảnh báo không làm fail compile/tests.

Git cảnh báo LF sẽ chuyển thành CRLF theo cấu hình Windows khi checkout.
Staged diff check PASS; không thay đổi Git config hoặc nội dung tài liệu Word.
