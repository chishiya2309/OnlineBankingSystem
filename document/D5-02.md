## 2. Cách kiểm thử

- Playwright Test + Chromium, một worker, retries = 0.
- Provider EIP-1193 được chèn vào browser context trước khi app tải; `eth_requestAccounts` và `accountsChanged` đi qua luồng ví của ứng dụng. `eth_sendTransaction` chuyển xuống tài khoản unlocked của node local, có giao dịch và receipt thật. Không giả lập kết quả `eth_call`, allowance, số dư, receipt hoặc event.
- Chỉ setup fixture (deploy/seed, chuyển NFT) và thay đổi thời gian dùng RPC/script trực tiếp. Gửi, rút, tái tục và quản trị đang được kiểm thử đều bắt đầu từ nút/form UI.
- Node riêng: `http://127.0.0.1:18545`, chain ID `31337`; UI: `http://127.0.0.1:5174`.
- Mỗi lần chạy tạo node mới và thư mục deployment riêng. Trước mỗi test, revert snapshot đã seed và tạo lại snapshot. Token snapshot được lưu để worker thay thế sau lỗi vẫn trở về baseline.
- Nếu cổng bận, harness báo lỗi thay vì sử dụng dịch vụ hiện có. Playwright dừng stack sau khi kết thúc; chạy demo thủ công dùng Ctrl+C.
- ABI, registry và manifests nằm trong `.e2e/runtime/<run-id>/`. Các file deployment/registry đang được Git quản lý không bị ghi đè bởi E2E.

## 4. Các lỗi tích hợp đã sửa

1. **Rút quỹ admin sai ABI:** thay `withdrawLiquidity(amount, recipient)` bằng `withdrawVault(amount)`, bỏ trường recipient và hiển thị đúng việc tiền về admin. Không thay đổi Solidity/API contract.
2. **Plan đã chọn giữ dữ liệu cũ:** đồng bộ selected plan theo ID sau refetch; chọn plan enabled tiếp theo nếu plan hiện tại bị disable.
3. **Manual renewal tự đổi plan:** danh sách enabled được tạo mới ở mỗi render làm effect liên tục reset lựa chọn về plan đầu tiên. Memoize danh sách và giữ lựa chọn đang hợp lệ. E2E xác nhận giao dịch thực sự vào plan #2.
4. **Pause chỉ hiện unknown custom error:** giải mã revert bytes từ provider bằng ABI, kể cả dạng metadata lồng nhau. Bổ sung unit tests với selector EnforcedPause thật.
5. **Test phụ thuộc deployment Sepolia cũ:** dùng fixture riêng để kiểm tra chain selection, giữ kiểm tra registry thực trong bộ test cấu hình/admin.
6. **Typecheck script deploy/demo:** khai báo kiểu kết quả retry và kiểm tra receipt đã mined trước khi truy cập.
7. **APR admin:** bỏ ký hiệu `%` bị lặp và dùng giá trị số đúng định dạng khi mở input sửa APR.

## 5. Chạy E2E

Chạy từ thư mục gốc bằng PowerShell; yêu cầu Node theo `.node-version`.

```powershell
npm.cmd ci
npm.cmd --prefix frontend ci
npx.cmd playwright install chromium
npm.cmd run typecheck
npm.cmd run typecheck:e2e
npm.cmd run test:e2e
```

Không cần MetaMask, RPC key hay private key riêng cho bộ E2E tự động.

```powershell
# Hiện trình duyệt khi chạy cùng các kịch bản
npm.cmd run test:e2e:headed

# Mở báo cáo lần chạy gần nhất
npm.cmd run test:e2e:report

# Chỉ chạy nhóm admin
npm.cmd run test:e2e -- --grep A0
```

Báo cáo HTML tại `.e2e/report/index.html`, JSON tại `.e2e/results.json`. Mỗi test có `on-chain.json` (transaction hash, block, timestamp, sender, calldata, logs và assertion), `ui.png`; khi lỗi có thêm screenshot và `trace.zip`.

Các biến cấu hình bổ sung:

| Biến | Ý nghĩa | Mặc định |
| --- | --- | --- |
| `LOCAL_RPC_URL` | Endpoint của network localhost trong Hardhat | `http://127.0.0.1:8545` |
| `VITE_LOCAL_RPC_URL` | RPC local cho read-only fallback và tham số thêm mạng | `http://127.0.0.1:8545` |
| `BANKING_ARTIFACT_ROOT` | Root riêng cho manifests, exports và bản export frontend; Vite đọc ABI/registry tương ứng | Root repository |

Harness tự đặt các biến trên và `SKIP_LOAD_ENV=true`; cấu hình demo local không phụ thuộc nội dung `.env` cá nhân.

## 6. Checklist demo MetaMask user/admin

Đây là hướng dẫn thao tác thủ công với extension MetaMask thật, tách biệt với kết quả tự động. Chưa ghi nhận phiên demo extension đã được thực hiện.

### Chuẩn bị

```powershell
npm.cmd run demo:local
```

Để terminal mở và truy cập `http://127.0.0.1:5174`. Stack tự deploy/seed giống E2E nhưng không chèn ví tự động.

Trong profile MetaMask dành cho local, dùng tài khoản mặc định của Hardhat. Mnemonic công khai của fixture Hardhat là `test test test test test test test test test test test junk`. Tạo lần lượt các account theo bảng trên: account đầu là #0, account thứ hai là Admin #1, kế tiếp là Alice #2 và Bob #3.

Đặt RPC của mạng Hardhat chain ID `31337` thành `http://127.0.0.1:18545`, symbol `ETH`. Nếu MetaMask đã lưu chain 31337 tại 8545, sửa RPC của mạng đó. Sau khi node được tạo lại, reset activity/nonce cache của tài khoản local nếu extension giữ nonce cũ.

### User Alice

1. Connect MetaMask bằng Alice; xác nhận đúng địa chỉ, network và số dư seed.
2. Chọn plan #1, nhập 1.000 USDC; Approve rồi Open Deposit, xác nhận từng giao dịch trong MetaMask.
3. Xem receipt, certificate ID mới và My Portfolio. Với early withdrawal, chọn Withdraw Early → Confirm; đối chiếu 965 USDC về Alice và 35 USDC về feeReceiver.
4. Mở deposit mới cho từng kịch bản maturity, manual renewal và auto renewal; lưu đúng ID từ UI.
5. Trong terminal khác, advance thời gian cho đúng certificate:

```powershell
# Thay 2 bằng ID thực tế đang Active
npm.cmd run demo:time -- --deposit 2
# Hoặc tới grace end cho một deposit Active khác
npm.cmd run demo:time -- --grace 3
```

6. Bấm Refresh Portfolio. Rút đáo hạn phải nhận P + I. Manual Renew chọn plan #2, kiểm tra P mới và lineage. Auto Renew giữ snapshot cũ và mint NFT mới về owner.

`demo:time` chỉ chấp nhận node riêng `127.0.0.1:18545`, chain 31337 và deposit Active. Script thay đổi thời gian blockchain bằng `evm_setNextBlockTimestamp`/`evm_mine`, không sửa điều khoản deposit bằng `setDepositTimeline`.

### Admin

1. Đổi sang Admin #1, vào Admin Portal; xem Bank Administrator Authenticated.
2. Tạo plan 45 ngày, APR 6%, penalty 4%; sửa APR; disable rồi enable. Đối chiếu plan trên màn user sau refresh/tải lại.
3. Mint 5.000 test USDC; Fund vault 500; Withdraw liquidity 200. Kiểm tra tiền rút về admin, vault tăng ròng 300 và principal trong Core không đổi.
4. Đổi feeReceiver sang Bob; mở/rút sớm một deposit Alice và xác nhận Bob nhận phí.
5. Emergency pause; Alice thử settlement và thấy lý do bị chặn. Admin unpause; Alice thao tác lại thành công.
6. Đổi về Alice/Bob và xác nhận Admin Portal hiển thị Restricted Access.

Để bắt đầu lại, Ctrl+C stack rồi chạy `demo:local` lần nữa. E2E kiểm chứng thêm NFT transfer bằng fixture RPC trước khi Bob rút qua UI; giao diện hiện không có chức năng chuyển NFT nên checklist không mô tả đây là một thao tác UI.

## 8. Giới hạn bằng chứng

E2E dùng giao dịch thật trên Hardhat local với provider EIP-1193 thử nghiệm, không chứng minh thao tác popup của extension MetaMask hoặc giao dịch Sepolia. U05 trigger auto-renew qua UI bằng owner; tính permissionless với caller khác owner được kiểm chứng bởi contract regression. Receipt local được lưu trước khi snapshot bị revert hoặc node dừng; hash không có đường dẫn explorer công khai.

Contract baseline có tiện ích admin `setDepositTimeline`; D5-02 không dùng tiện ích này để làm deposit đáo hạn và không thay đổi quyền của nó. Các assertion về snapshot trong task này xác minh APR/penalty theo luồng plan/renewal, không phải tuyên bố toàn bộ điều khoản bất biến trước mọi API admin hiện có.
